## 5 · Koruma kuralları (hepsi sunucuda)

Kurallar `services/users.py`'de **tek fonksiyonda**: hem `GET /users/{id}`'nin `actions` alanını hem yazma uçlarını besler. Böylece arayüzdeki pasif düğme ile sunucu reddi ayrışamaz.

| İşlem | Reddedilen durum | Cevap |
|---|---|---|
| Rol değiştir | Kendi rolü | 409 `user_protected` |
| | Hedef System owner | 409 |
| | Hedef son aktif Admin, yeni rol Admin değil (soru 6) | 409 |
| | Hedef pasif (soru 8) | 409 |
| | Yeni rol System owner, işlemi yapan değil | 403 `forbidden` |
| Şifre sıfırla | Kendi şifresi (menüden değiştirir) | 409 |
| | Hedef pasif | 409 |
| | Hedef System owner, işlemi yapan değil (soru 4) | 403 `forbidden` |
| Kilidi aç | Hesap kilitli değil | 409 |
| Kapat | Kendisi · hedef System owner · son aktif Admin · zaten pasif | 409 |
| Geri aç | Zaten aktif | 409 |
| Kullanıcı ekle | Rol System owner, işlemi yapan değil | 403 `forbidden` |

- Reddedilen her istek denetim izine "Yetkisiz istek" olarak düşer (`authz.record_denial`, sebebiyle).
- Mesajlar neden söyler; ör. "Son aktif Admin kapatılamaz. Önce başka bir Admin açın."
- "Son aktif Admin" denetimi aktif Admin satırlarını işlem içinde kilitler.

**Kullanıcı adı (soru 10):** `^[a-z][a-z0-9._-]{1,59}$`. Çakışmada öneri: pasifler dahil boş olan ilk `ad2`, `ad3`…; aynı anda açılırsa benzersiz indeks hatası da 409'a çevrilir. Sonradan değiştirilemez: böyle bir uç yok.

**Geçici şifre:** `security.temporary_password(policy, user_name)`; uzunluk `max(12, PasswordMinLength)`, `policy_problems` boş dönene kadar üretilir. Sıfırlamada geçmiş korunur. Şifre hiçbir yerde saklanmaz; veritabanında yalnız Argon2id özeti durur.

**Rol kapsamı metinleri** (docs/12 ve `tr.ts`; K-99 ve matrisle uyumlu):
- **System owner:** Bütün fonksiyonlar; motor, lisans ve sürüm dahil.
- **Admin:** Kullanıcı, entegrasyon, zamanlanmış işler ve sistem sağlığı; Key user'ın bütün yetkileri. System owner ayarları hariç.
- **Key user:** Veri, parametre, planlama ve yayın. Çalışmaların yalnız kendisininkini değiştirir.
- **End user:** Ana veri, malzeme ve analiz sonuçları ile raporları görür; görünüm, koşullu biçim ve Excel serbest. Fonksiyon çalıştıramaz, veriyi değiştiremez.
